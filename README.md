# 📘 FB-Clone-Website

This repository contains a **Facebook clone project** that I created as part of my journey to learn and practice **Git** and **GitHub**.  
The goal of this project was not to build a production-ready social media platform, but rather to understand how version control works, how to collaborate using GitHub, and how to structure a web project effectively.

---

## 🚀 Project Overview
- A simple **Facebook-like interface** with basic features such as:
  - User login/signup (mocked or static for now)
  - Newsfeed layout
  - Profile page structure
  - Post creation and display
- Focused mainly on **frontend design** and **UI replication** rather than backend functionality.

---
